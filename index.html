Touhou.sf2 — 全音色对照表

185 个音色 · 14 套鼓组 · 完全解析自文件本身
音名怎么看：本表用国际记法，中央 C = C4（MIDI 音符号 60）。
往上一个八度是 C5、C6；往下是 C3、C2。# = 升号，例如 F#4 = 中央 C 上方 6 个半音。
表里写「C3 – G4」的意思：从 C3 到 G4 这一段音高，用的是这条采样。
「bank」和「program」是什么：这是音色库的两个编号。可以这样理解——
program = 音色本体（比如"小号"是 56 号）；bank = 同一个音色的第几个版本。
bank 0 是标准版；bank 1、8、24 这些是同一个乐器的另一种录音版本（更亮、更闷、加了效果等）。 这些版本全部是这个 sf2 文件里原本就有的，不是我编的——你把文件丢进软件，它自己就会列出来。
页面最下面那一节「扩展音色」就是这些非 bank 0 的版本，你平时用不到可以先不管。
术语小词典（看不懂的先来这查）：
  • 主音 / Lead —— 负责吹主旋律的那个音色，站在最前面的
  • 铺底 / Pad —— 铺在背景里的一层，不抢戏，像雾或者地毯
  • 失真 —— 把声音故意弄脏、弄粗糙
  • 复音 —— 能同时发出好几个音
  • 808 / 909 —— 两台很有名的电子鼓机。808 的低音"咚——"拖得长，909 的短促
  • GM —— 通用 MIDI 标准：128 种乐器固定的编号，全世界都一样
一个音色 ≠ 一个琴键：普通音色（钢琴、小号、弦乐）是整个键盘都同一个音色，只是按键不同音高不同。 只有一个例外——bank 128 的鼓组，那里才是每个琴键一个单独的打击乐。
在「玩酷电音」里怎么选：音色 = bank 号 + program 号。 bank 0 是标准音色（下面按类别分好了）；bank 8 / 1 / 24 等是同一乐器的变体版本，在最后「扩展音色」里。
鼓组在 bank 128，下面有完整的 14 套。建议先展开「铜管」那组听几个号类音色。

🥁 bank 128 鼓组（14 套，点开看每个键是什么）

鼓组跟普通音色不一样：普通音色是「整个键盘同一个音色，只是音高不同」； 鼓组是每个琴键 = 一个单独的打击乐。下面每套鼓都是 14 套里的一套（换 program 号就换一套）。

📥 安装教程：怎么把这个音色装进 App

以「玩酷电音」为例，它读音色的目录是这一个：
/sdcard/Android/data/com.viscentsoft.coolbeat/files/Asset/SoundFont/
（其他 App 一般在设置里能看到自己的音色目录）
步骤做什么
1拿到一个 .sf2 文件（SoundFont 音色包）
2把它复制进上面那个 SoundFont 文件夹
3完全退出玩酷电音（后台划掉，不是返回键）
4重新打开 → 新建音轨 → 选音色 → 列表里就有它了
⚠️ Android 11 之后有个坑：Android/data 这个文件夹用普通文件管理器 打不开（系统锁了）。三个办法：
① 用 MT 管理器或 Material Files 这类能申请特殊权限的 App；
② 插电脑，用 USB 传（最稳）。
怎么用新装进去的音色：在 App 里选音色时，先选 bank，再选 program 号。
同一份 Touhou.sf2 里：bank 0 是普通音色，bank 128 是鼓组。
听不到声音 / 有噪音？音色包越大越吃内存。261 MB 的 Touhou.sf2 属于很大的， 如果卡或者爆音，是手机内存不够，不是文件坏了——换个小的 sf2 就好。
